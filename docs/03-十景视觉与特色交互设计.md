# 第三章 “西湖十景” 3D 视觉与特色交互设计规范

本章针对“西湖十景”中最具代表性的场景，详细规范其核心视觉元素、Shader 着色器机制、物理/粒子特效及专属交互逻辑。

---

## 3.1 苏堤春晓 (Spring Dawn at Su Causeway)

### 视觉意境
薄雾破晓，两堤杨柳拂水，桃花夹岸竞相吐艳。空气中充满晨露湿气与微光透射感。

### 核心视觉元素
- 贯穿湖面的长堤与古桥（压低视角，强调纵深）
- 柳枝柔性骨骼与叶片程序化风场摆动
- 飘落桃花瓣 GPU Instanced 粒子
- 晨雾渐变与低角度丁达尔光束

### Shader & 交互实现规范

#### 1. 程序化风场与柳枝摆动 Vertex Shader
利用 Simple Noise + 3D Vector Field 驱动骨骼/顶点偏移：

```glsl
// 柳枝风场顶点摆动 Shader 片段
uniform float uTime;
uniform vec3 uWindDirection; // 风向向量，默认 vec3(1.0, 0.2, 0.5)
uniform float uWindStrength;  // 风力强度，默认 0.8

attribute float aBranchFlexibility; // 顶点灵活性权重 (0=树干, 1=枝条末端)

void main() {
    vec3 pos = position;
    
    // 风场波动：正弦波 + 高频噪声
    float wave = sin(uTime * 2.5 + pos.x * 0.5 + pos.z * 0.5) * 0.6
               + cos(uTime * 4.0 + pos.y * 1.0) * 0.4;
               
    vec3 displacement = uWindDirection * wave * uWindStrength * aBranchFlexibility;
    pos += displacement;

    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
}
```

#### 2. 落英粒子与交互扰动
- **粒子系统：** `InstancedMesh` 渲染 3,000 片桃花瓣。
- **划过交互：** 鼠标快速划过屏幕时，计算 Raycast 在 3D 空间中的向量，在轨迹周围半径 5 units 内产生一个局部漩涡风力 `uMouseVortex`，促使花瓣向上盘旋飘散后缓缓沉降。

## 3.2 三潭印月 (Three Pools Mirroring the Moon)

### 视觉意境
夜色如水，三座石塔伫立湖中。月影沉璧，塔内烛光从十五个圆孔透出，在波光粼粼的水面折射出多重月影。

### 核心视觉元素
- 湖心三座精雕三潭石塔
- 屏幕空间水面反射（SSR）与月华泛光
- 石塔透光与水面倒影重叠

### Shader & 交互实现规范

#### 1. 水面折射与多月透光 Shader
```glsl
// 三潭透光与多重月影 Fragment Shader
uniform sampler2D uWaterNormalMap;
uniform float uTime;
uniform vec3 uMoonPosition;
uniform vec3 uTowerPositions[3]; // 三塔世界坐标

varying vec3 vWorldPosition;
varying vec3 vNormal;

void main() {
    vec2 distUV = vWorldPosition.xz * 0.1 + vec2(uTime * 0.02);
    vec3 normalMod = texture2D(uWaterNormalMap, distUV).rgb * 2.0 - 1.0;
    vec3 N = normalize(vNormal + normalMod * 0.15);

    // 计算月光与塔光反射
    float moonReflect = pow(max(0.0, dot(reflect(-normalize(uMoonPosition - vWorldPosition), N), normalize(cameraPosition - vWorldPosition))), 32.0);
    
    // 三塔 15 孔烛光水面折射计算
    float towerGlow = 0.0;
    for(int i=0; i<3; i++) {
        float d = distance(vWorldPosition.xz, uTowerPositions[i].xz);
        towerGlow += smoothstep(8.0, 0.0, d) * (sin(uTime * 3.0 + float(i)) * 0.2 + 0.8);
    }

    vec3 finalColor = vec3(0.05, 0.12, 0.2) + vec3(0.9, 0.8, 0.5) * (moonReflect + towerGlow * 0.5);
    gl_FragColor = vec4(finalColor, 0.92);
}
```

#### 2. 交互机制
- **点击石塔孔洞：** 激活内部鎏金光芒闪烁，并在水面上生成金色涟漪。三塔全部点亮时，生成连线星辉光束。

## 3.3 断桥残雪 (Lingering Snow on Broken Bridge)

### 视觉意境
冬日残雪，桥阳面雪化水淌，阴面白雪皑皑。远处望去桥面若断若连，墨色湖水与残雪形成强烈水墨对比。

### 核心视觉元素
- 石拱断桥与石阶
- 残雪渐变与融雪流光
- 枯枝倒影与薄冰水面

### Shader & 交互实现规范

#### 1. 融雪 Vertex & Dissolve Material
通过控制 `uTemperature` (温度参数: 0°C ~ 15°C) 驱动白雪材质的溶解与倾斜面消融：

```glsl
// 融雪溶解 Shader
uniform float uTemperature; // 0.0 为大雪覆盖, 1.0 为雪融净
uniform sampler2D uDissolveNoise;

varying vec3 vNormal;
varying vec2 vUv;

void main() {
    float noise = texture2D(uDissolveNoise, vUv * 4.0).r;
    float slope = clamp(dot(vNormal, vec3(0.0, 1.0, 0.0)), 0.0, 1.0);
    
    // 陡峭面先融化，平坦面后融化
    float snowMask = step(uTemperature * 1.2, slope * noise);
    
    vec3 snowColor = vec3(0.93, 0.92, 0.90); // 月白
    vec3 stoneColor = vec3(0.2, 0.2, 0.22);  // 松烟石色

    vec3 color = mix(stoneColor, snowColor, snowMask);
    gl_FragColor = vec4(color, 1.0);
}
```

#### 2. 交互机制
- **温度滑块/手势拖拽：** 用户横向滑动界面上的“冷暖天时”滑块，桥面白雪实时沿屋檐和石阶沿线融化为冰露，滴落湖中溅起细微水花粒子。

## 3.4 曲院风荷 (Wind-Ruffled Lotus at Breeze Winery)

### 视觉意境
盛夏荷塘，绿云摇曳，粉荷娉婷。清风拂过，酒香与荷香随水雾弥漫。

### 核心视觉元素
- 密集错落的荷叶与半透荷花
- 荷叶表面水珠物理滚动与聚合
- 荷叶次表面散射 (Subsurface Scattering, SSS)

### Shader & 交互实现规范

#### 1. 荷叶半透光 SSS Shader
采用近似 SSS 技术，表现阳光穿透荷叶时的鲜嫩翠绿感：

```glsl
// 荷叶 Subsurface Scattering Shader 片段
uniform vec3 uSubsurfaceColor; // #7BA07A 汁绿
uniform float uSSSDistortion;
uniform float uSSSScale;

vec3 getSubsurfaceLight(vec3 lightDir, vec3 normal, vec3 viewDir, vec3 color) {
    vec3 subLightDir = lightDir + normal * uSSSDistortion;
    float subDot = pow(clamp(dot(viewDir, -subLightDir), 0.0, 1.0), 3.0) * uSSSScale;
    return color * subDot;
}
```

#### 2. 水珠表面张力交互
- **荷叶露珠：** 荷叶表面设有物理 Raycast 碰撞区。鼠标在荷叶上移动时，驱动一颗大水珠滚动，吸附周围小水珠并逐渐变大，重力超出阈值后顺着叶片边缘滑落滴入湖面。

## 3.5 雷峰夕照 (Leifeng Pagoda in Sunset)

### 视觉意境
夕阳西下，晚霞如血，雷峰塔凌空耸立。塔身在炽烈逆光中呈现沉稳剪影，边缘镀上一层耀眼的金色轮廓光。

### 核心视觉元素
- 巍峨古塔与远山剪影
- 大气散射渐变天空盒 (Atmospheric Scattering)
- 强烈的菲涅尔边缘光 (Fresnel Rim Light)

### Shader & 交互实现规范

#### 1. 逆光金边 Fresnel Edge Light Shader
```glsl
// 雷峰塔逆光金边 Shader
uniform vec3 uRimColor;     // #C5A55A 鎏金
uniform float uRimPower;    // 3.5
uniform float uRimIntensity;// 2.0

varying vec3 vNormal;
varying vec3 vViewPosition;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 viewDir = normalize(-vViewPosition);

    float rim = 1.0 - clamp(dot(normal, viewDir), 0.0, 1.0);
    rim = pow(rim, uRimPower) * uRimIntensity;

    vec3 baseColor = vec3(0.08, 0.07, 0.06); // 暗部木石剪影
    vec3 finalColor = baseColor + uRimColor * rim;

    gl_FragColor = vec4(finalColor, 1.0);
}
```

#### 2. 交互机制
- **拖拽控制太阳升落：** 随着太阳落入山脊，背景从橙红晚霞过度至黛蓝静夜，雷峰塔的风铎铜铃声随风响起。

## 3.6 南屏晚钟 (Evening Bell Ringing at Nanping Hill)

### 视觉意境
暮色笼罩山林古刹，深沉古钟声震破静谧。声波形变几何体在空中呈金光扩散，惊起林中白鹭盘旋。

### 核心视觉元素
- 古刹古钟悬挂于钟楼
- 空间声波金光扩展环 (Audio Visualizer Mesh)
- 惊飞白鹭 GPU 鸟群 (Flocking Boids System)

### Shader & 交互实现规范

#### 1. 声波扩散 Vertex Displacement Shader
```glsl
// 声波顶点形变环 Shader
uniform float uWaveProgress; // 0.0 -> 1.0 扩散进度
uniform float uWaveAmplitude;

varying vec2 vUv;

void main() {
    vec3 pos = position;
    float dist = length(uv - vec2(0.5));
    
    // 环状波纹推顶
    float wave = sin((dist - uWaveProgress) * 20.0) * exp(-dist * 4.0);
    pos.z += wave * uWaveAmplitude;

    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
}
```

#### 2. 交互机制
- **撞击古钟：** 点击 3D 铜钟模型，播放低沉钟声 Audio，触发以钟为中心的金光声波向外扩散，周围树林抖落树叶，鸟群按照 Flocking 算法自古刹惊飞飞向天际。
