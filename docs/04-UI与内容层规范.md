## 4.1 宋代典籍排版风格

### 4.1.1 字体与字号规范

采用宋代古籍刻本与碑刻拓片风格，优先选用传统中式雕版印刷体：

- **主标题/诗词：** 思源宋体 / 方正清刻本悦宋 / 汉仪字体（降级方案：`Noto Serif SC`, `"Songti SC"`, `SimSun`, `serif`）
- **UI 标签/正文：** 楷体 / 细宋体
- **印章文字：** 方正小篆 / 九叠篆字体（SVG / Path 矢量渲染）

### 4.1.2 竖排非对称排版 (Vertical Writing Mode)

所有诗词与景点介绍默认采用竖排文本流：

```css
/* 竖排古籍文本样式规范 */
.poem-vertical-container {
  writing-mode: vertical-rl;
  text-orientation: upright;
  letter-spacing: 0.35em;
  line-height: 2.2;
  font-family: "Noto Serif SC", "Songti SC", serif;
  color: #2c2c2c; /* 松烟墨 */
  text-shadow: 0 0 1px rgba(0, 0, 0, 0.1);
  user-select: none;
}
```

### 4.2.2 盖章打卡交互机制（盖印即拍照）

进入景点后，用户主动按下「盖印」按钮（诗词浮层）完成打卡：
盖印不只记录印章，还会把用户当前调好的视角渲染成一张照片，
合成印章与落款后收入图册：

```
进入景点 ──> 调整视角 ──> 点击「盖印」
  │
  ├─ 快门闪光 + 落盖音效；截取 WebGL 最终帧（需 preserveDrawingBuffer）
  ├─ 压缩为 JPEG，合成右下朱砂印章 + 左下景致名/日期落款
  ├─ 已盖印再按一次即重拍，新视角照片覆盖旧照片
  ├─ 底部印章坞对应项同步点亮（朱砂底 + 米白字）
  └─ 存入 Zustand 状态（与印章同生命周期）
```

**《游历图册》展示**：已盖印景致的格子不再只画印章，
而是以明信片形式展示当时拍下的照片（contain 完整展示不裁剪，
保住底部书法落款与印章），照片铺满整格；照片内已含景致名落款，
格子底部不再重复绘制名字/拼音，避免框中框；无照片时回退为纯印章展示。

**状态配色规范**：`.stamp-seal` 只管外形（书法字、圆角、内晕），
边框用 `currentColor` 随文字色，文字/底色完全由工具类控制，
避免出现红底红字看不清的穿帮。

### 4.2.3 《西湖游历图册》生成与导出

集齐十景印章后，用户可点击“导出图册”：
- **生成机制：** 利用 HTML5 Canvas / OffscreenCanvas 动态拼接：
  - 背景：高分辨率宣纸底纹
  - 中央：十景拼接全景长卷（Low-Poly 水墨渲染快照）
  - 右侧：竖排集齐印章与游历时间落款
  - 底部：个人专属 QR Code 与西湖水墨签名
- **导出格式：** 支持导出高清晰度 PNG 画卷分享至社交平台。
- **保存兼容策略（三级降级链，依据小红书《小工具容器能力清单》）：**
  小工具是纯离线 Web 沙箱，禁 `a[download]`、禁外链、禁长按菜单，
  但容器自动注入官方 JS API SDK `window.xhs.miniTool`，按环境自动降级：
  1. **小工具容器**：调 `saveImageToPhotosAlbum({ filePath })` 存入系统相册；
     图册为大图，先 `writeTempFile({ data })` 换成临时 filePath 再传，
     失败回退直传 dataURL（filePath 也接受 `data:` base64）。
     调用约定：唯一入口 `window.xhs.miniTool.<api>(options)`，不传回调时返回 Promise，
     参数按 JSON Schema 校验不得多传字段，需用户主动点击触发；
  2. **普通移动端 WebView**：弹出全屏大图层引导长按保存；
     大图需恢复 `user-select: auto` + `-webkit-touch-callout: default`
     （全局 `* { user-select: none }` 会压制长按菜单）；
  3. **桌面浏览器**：常规 `a[download]` 文件下载。
  按钮文案随环境切换：存入相册 / 保存画卷 / 导出全景画卷 PNG。
  额外端能力：小工具内提供「发布为笔记」按钮，调 `postNote` 把图册带入
  小红书笔记发布页（标题≤20 字，媒体字段只接受 base64/本地路径）。

## 4.3 三维诗词意境浮层 (3D Parallax Poetry)
