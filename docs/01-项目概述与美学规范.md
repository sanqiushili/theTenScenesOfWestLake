## 第一章 项目概述

### 1.1 项目愿景

打造一个以**西湖十景**为主题的国风 Three.js 沉浸式网站。打破传统"静态图文 + 旋转 3D 模型"的陈旧展示形式，将**宋代水墨写意美学**与**现代着色器（Shaders）、程序化粒子系统、流体动态模拟**深度融合，呈现一个可交互、可漫游、可感知时空流转的数字西湖。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **写意优于写实** | 不追求照片级真实渲染，追求宋画水墨韵味的程序化表达 |
| **虚实相生** | 体积雾、景深、墨迹扩散等手法营造"留白"与"空灵" |
| **动静皆宜** | 静态时如画，交互时如诗，每一帧皆可截屏为壁纸 |
| **性能为纲** | 60fps 为底线，移动端可降级为 30fps + 简化后处理 |
| **文化敬畏** | 所有诗词、典故、印章须经考证，不做戏说 |

### 1.3 目标平台与性能基准

| 平台 | 最低帧率 | 渲染分辨率 | 后处理级别 |
|------|---------|-----------|-----------|
| 桌面端 (Chrome/Safari/Edge) | 60fps | 原生 | 全量 |
| 平板 (iPad Pro) | 45fps | 0.85x | 简化 Bloom + 关闭 SSR |
| 移动端 (iPhone 14+) | 30fps | 0.7x | 仅基础调色 + 简化粒子 |

### 2.2 材质规范

#### 2.2.1 宣纸纤维噪点材质

所有 3D 模型表面叠加宣纸纤维质感，通过法线扰动实现：

```glsl
// 宣纸纤维法线扰动 — 核心 Fragment Shader 片段
uniform float u_paperGrain;      // 推荐值: 0.03 ~ 0.08
uniform float u_paperScale;      // 推荐值: 80.0 ~ 150.0

vec3 applyPaperTexture(vec3 normal, vec2 uv) {
    float noise = perlinNoise(uv * u_paperScale);
    float fiber = abs(sin(uv.x * 300.0 + noise * 5.0)) * 0.5
                + abs(sin(uv.y * 280.0 - noise * 3.0)) * 0.5;
    vec3 perturbedNormal = normalize(
        normal + vec3(fiber * u_paperGrain, fiber * u_paperGrain, 0.0)
    );
    return perturbedNormal;
}
```

**参数约束：**
- `u_paperGrain`：0.03（远景）~ 0.08（近景特写），不得超过 0.12
- `u_paperScale`：随相机距离动态调整，保持纤维颗粒在屏幕上约 1~2px 大小

#### 2.2.2 水墨边缘描边（Edge Inking Shader）

后处理阶段基于深度与法线不连续性检测边缘，叠加毛笔笔触质感：

```glsl
// Edge Inking 后处理 — 核心逻辑
uniform sampler2D tDepth;
uniform sampler2D tNormal;
uniform float u_edgeThreshold;   // 推荐: 0.15
uniform float u_inkWidth;        // 推荐: 1.5 ~ 2.5 px
uniform vec3  u_inkColor;        // 推荐: vec3(0.17, 0.17, 0.17) 松烟墨

float detectEdge(vec2 uv) {
    float depthCenter = texture2D(tDepth, uv).r;
    float depthL = texture2D(tDepth, uv - vec2(texelSize.x, 0.0)).r;
    float depthR = texture2D(tDepth, uv + vec2(texelSize.x, 0.0)).r;
    float depthU = texture2D(tDepth, uv - vec2(0.0, texelSize.y)).r;
    float depthD = texture2D(tDepth, uv + vec2(0.0, texelSize.y)).r;

    float edgeDepth = abs(depthL - depthR) + abs(depthU - depthD);

    // 法线边缘检测
    vec3 normalCenter = texture2D(tNormal, uv).rgb;
    vec3 normalL = texture2D(tNormal, uv - vec2(texelSize.x, 0.0)).rgb;
    float edgeNormal = 1.0 - dot(normalCenter, normalL);

    return smoothstep(u_edgeThreshold - 0.05, u_edgeThreshold, edgeDepth + edgeNormal);
}
```

**描边风格要求：**
- 线条粗细不均匀，模拟毛笔运笔的"提按"效果
- 线条末端自然收细消失，避免生硬截断
- 边缘处可叠加微弱的墨迹扩散（Gaussian Blur 1px + 透明度 0.3）

#### 2.2.3 水体材质分层规范

| 层级 | 深度范围 | 视觉表现 | 实现方式 |
|------|---------|---------|---------|
| 表层反射 | 0cm | 天空/建筑倒影 + 微波 | SSR + Fresnel |
| 浅水区 | 0~50cm | 清澈透亮、可见湖底 | 半透明 + 焦散投影 |
| 中水区 | 50~200cm | 墨色渐浓、光线散射 | 体积散射 + 颜色渐变 |
| 深水区 | 200cm+ | 水墨晕染不透明 | 纯色渐变 #2F4F6F → #1A1A2E |

### 2.3 后处理管线（Post-Processing Pipeline）

按顺序执行以下后处理通道：

```
渲染场景
  │
  ├─① SSAO（屏幕空间环境光遮蔽）
  │     radius: 0.5, intensity: 0.3
  │
  ├─② SSR（屏幕空间反射）— 仅水面
  │     maxDistance: 10, thickness: 0.02
  │
  ├─③ Edge Inking（水墨描边）
  │     见 §2.2.2
  │
  ├─④ Depth of Field（景深）
  │     focalLength: 动态跟随焦点, bokehScale: 2.5
  │
  ├─⑤ UnrealBloomPass（辉光）
  │     threshold: 0.85, strength: 0.4, radius: 0.6
  │
  ├─⑥ Color Grading（调色）
  │     ToneMapping: ACESFilmicToneMapping
  │     exposure: 1.1
  │     应用季节色温偏移（§2.1.2）
  │
  ├─⑦ Film Grain（宣纸颗粒）
  │     intensity: 0.06, animated: true
  │
  └─⑧ Vignette（暗角）
        offset: 0.3, darkness: 0.4
```

**性能降级策略：**
- 中等画质：关闭 SSR + SSAO，Bloom 分辨率减半
- 低画质：仅保留 Color Grading + Film Grain + Vignette
