### 2.2.2 俯冲过渡运镜

用户点击景点墨点后，摄像机沿三维贝塞尔曲线俯冲：

```javascript
// 俯冲运镜核心逻辑 (伪代码)
const cameraPath = new THREE.CubicBezierCurve3(
  currentPos,                          // P0: 当前鸟瞰位置
  new THREE.Vector3(mid.x, 80, mid.z), // P1: 上提，穿越云层
  new THREE.Vector3(mid.x, 30, mid.z), // P2: 下压，穿过飞鸟
  targetSceneEntryPoint                // P3: 景点入口
);

// GSAP 驱动插值
gsap.to(progress, {
  value: 1,
  duration: 3.5,        // 总时长 3.5s
  ease: "power2.inOut", // 缓入缓出
  onUpdate: () => {
    const point = cameraPath.getPoint(progress.value);
    camera.position.copy(point);
    camera.lookAt(targetLookAt);
  }
});
```

**运镜规范：**
- 总时长：3.0s ~ 4.0s，不可低于 2.5s（过快眩晕）、不可超过 5.0s（过慢无聊）
- 穿越云层时触发：云雾粒子密度临时增加 3x → 散开
- 穿越飞鸟时触发：鸟群粒子向两侧闪避
- 到达景点时触发：水墨晕染从屏幕中心向外扩散揭幕

### 2.3.2 湖面流体涟漪

鼠标划过水面区域时触发涟漪扩散：

```glsl
// 涟漪叠加到水面 Height Map
uniform vec2  u_rippleCenter;   // 鼠标命中水面的 UV 坐标
uniform float u_rippleTime;     // 涟漪计时器
uniform float u_rippleStrength; // 推荐: 0.03

float ripple(vec2 uv) {
    float dist = distance(uv, u_rippleCenter);
    float wave = sin(dist * 40.0 - u_rippleTime * 6.0)
               * exp(-dist * 8.0)
               * exp(-u_rippleTime * 1.5)
               * u_rippleStrength;
    return wave;
}
```

**涟漪规范：**
- 最多同时存在 8 个涟漪源（FIFO 淘汰）
- 涟漪扩散半径最大 15 units 后自然衰减
- 涟漪与风场叠加，顺风方向扩散更远

### 2.3.3 ScrollTrigger 叙事系统

滚轮/触摸滑动同时驱动三个维度：

```
滚动量 (0% → 100%)
  │
  ├─ 维度 1: 镜头位置 — 沿预设路径前进
  │
  ├─ 维度 2: 时间流转 — 驱动昼夜/天气变化
  │    0%  = 薄雾破晓
  │    30% = 晨光万道
  │    60% = 午后斜阳
  │    100%= 月上柳梢
  │
  └─ 维度 3: 叙事内容 — 触发诗词浮现/UI 变化
       20% = 第一段诗词淡入
       50% = 核心交互提示出现
       80% = 印章盖章动画
```

## 2.4 空间音频规范

```

  │
  ├─ AmbientBus (环境音总线)
```

## 2.5 场景过渡动效规范

### 2.5.1 水墨晕染遮罩

场景切换时使用水墨晕染作为转场遮罩：

```
时间线:
0.0s ─── 墨点从屏幕中心出现 (scale: 0 → 0.1)
0.3s ─── 墨迹向外扩散晕染 (噪点驱动的不规则边缘)
0.8s ─── 覆盖全屏 (此时切换底层场景)
1.2s ─── 墨迹从中心开始"吸收"消散
1.8s ─── 新场景完全揭露
2.0s ─── 过渡结束
```

**实现要点：**
- 使用全屏四边形 + 自定义 Shader
- 晕染边缘由 FBM 噪声驱动，每次过渡图案不同
- 墨色透明度从 0.95（非纯黑，保留宣纸底色透出感）

### 2.5.2 返回总览过渡

从景点返回总览时执行反向运镜：
- 镜头沿路径回撤 + 拉升高度
- 视野从 55° 渐变回 45°
- 景点场景在镜头离开后延迟 1s 卸载释放内存
