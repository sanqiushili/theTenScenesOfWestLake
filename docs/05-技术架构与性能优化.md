## 5.2 资产轻量化与模型规范

### 5.2.1 模型与纹理烘焙规范

- **多边形面数限制：**
  - 长卷总览场景：总面数 ≤ 80,000 面
  - 单个景点微观场景：总面数 ≤ 120,000 面
- **网格压缩：** 所有 `.gltf` / `.glb` 必须经由 `gltf-pack` 或 `Draco` 压缩：
  ```bash
  gltf-pipeline -i scene.gltf -o scene.glb -d --draco.compressionLevel 9
  ```
- **贴图规格：**
  - 弃用大尺寸 Diffuse 贴图，主靠程序化 GLSL Vertex/Fragment 颜色与烘焙 AO
  - 法线贴图 (Normal Maps) 与宣纸笔触贴图限制在 1024x1024 (PNG/WebP)
  - 单场景几何体与资产压缩包体积强制控制在 **2MB 以内**。

## 5.3 InstancedMesh 与 GPU 颗粒渲染

所有重复对象（桃花瓣、荷叶、鸟群、落雪、雨滴）必须使用 `InstancedMesh` 或 GPU Particle System 实现：

```tsx
// R3F 实例化桃花瓣示例
import { useRef } from 'react';
import * as THREE from 'three';
import { useFrame } from '@react-three/fiber';

export function PetalInstancedParticles({ count = 3000 }) {
  const meshRef = useRef<THREE.InstancedMesh>(null!);
  const dummy = new THREE.Object3D();

  useFrame((state) => {
    const time = state.clock.getElapsedTime();
    for (let i = 0; i < count; i++) {
      // 在 GPU 侧快速更新 3,000 个花瓣的位置与旋转
      dummy.position.set(
        Math.sin(time + i) * 10,
        ((i * 0.1 + time) % 20) - 10,
        Math.cos(time + i * 0.5) * 10
      );
      dummy.rotation.set(time * 0.2, time * 0.1, 0);
      dummy.updateMatrix();
      meshRef.current.setMatrixAt(i, dummy.matrix);
    }
    meshRef.current.instanceMatrix.needsUpdate = true;
  });

  return (
    <instancedMesh ref={meshRef} args={[undefined, undefined, count]}>
      <planeGeometry args={[0.2, 0.2]} />
      <meshBasicMaterial color="#C45A65" transparent opacity={0.8} />
    </instancedMesh>
  );
}
```

## 5.4 LOD (Level of Detail) 分级渲染策略

采用 Drei `<Detailed>` 节点或 Three.js `LOD` 管理远近景：

```
距离摄像机:
  0 ~ 15 units   --> 近景高精 3D 结构 (Full Mesh + Custom Shaders)
  15 ~ 50 units  --> 中景中模 (Low-Poly + Baked Normal)
  > 50 units     --> 远景 2D 水墨 Billboard 面片 (贴图带 alpha 渐变)
```

## 5.5 分块流式加载与预加载 (Chunk Streaming)

```
用户首次进入页面
  │
  ├─ 1. 下载全局骨架 + 宣纸背景 (< 300KB)
  ├─ 2. 加载总览微缩长卷 Scene Overview (< 1.5MB)
  ├─ 3. 用户在总览游览，后台利用 RequestIdleCallback 静默预加载当前焦点景点的资产
  └─ 4. 用户点击景点，瞬间切换进入，其余景点资产保持未加载状态，节约内存与带宽
```

## 5.6 性能预算与降级清单 (Performance Budget)

| 检查项 | 目标指标 | 警告阈值 | 极限降级动作 |
|------|---------|---------|-------------|
| **FPS** | 60 fps | < 45 fps | 降低后处理分辨率 (0.75x) |
| **Draw Calls** | < 80 | > 120 | 合并同材质 Mesh，开启 Instancing |
| **GPU 显存占用** | < 250MB | > 400MB | 释放未激活景点的 Texture 纹理 |
| **首屏加载 (FCP)** | < 1.5s | > 3.0s | 展示水墨笔触 Loading 渐显 |
| **Triangle Count** | < 200k | > 350k | 开启 LOD，强制截断远景 |
